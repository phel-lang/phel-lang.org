Phel ships more than the core language. These modules come with every install, no extra package needed. **Schema Validation** checks, coerces, and generates data with `phel.schema`. **Data Formats** reads and writes EDN and Transit. The **AI Module** talks to LLMs for chat, tool use, and embeddings. Each page is a narrative overview. The [API](/documentation/reference/api/) has every signature.
