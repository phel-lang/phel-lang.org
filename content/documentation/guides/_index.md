Want to build something? **Build a Web App** walks through a complete guestbook end to end. Coming from PHP? Start with the **Rosetta Stone**. Coming from Clojure? Start with **Coming from Clojure**. Want working code for common tasks? Open the **Cookbook**. Three guides cover built-in libraries: **Schema Validation** for checking and coercing data, **Data Formats** for EDN and Transit, and the **AI Module** for LLM chat, tools, and embeddings.
