# Homepage (content/_index.md + templates/index.html)

Mode: Persuade. Scope: homepage only; header, footer and docs keep the incumbent look. All current copy and facts stay; only structure and presentation change. Code-led (no image generation).

Audience: PHP devs and Lispers deciding whether to try Phel. Action: open the browser REPL or run an install command. Proof: real REPL transcript, real `phel compile` output, runnable snippets, DOOM.

## Direction contract

THESIS: A quiet editorial page that reads like a well-set book about a language, where every claim sits beside the code that proves it. Refuses the SaaS hero + card grid + centered-section stack. Grammar pinned by the user from pi.dev; identity is Phel's.

OWN-WORLD: Violet-ink canvas (dark) / lavender paper (light), one accent: Phel purple. Brygada 1918: italic for display, roman for body (the well-set book), pixel mono (Departure Mono) only for commands, labels and s-expression buttons written as `(try-it)`. Hairline panels with corner ticks, faint 20px grid.

STORY: Visitor learns what Phel is in one line, sees real code, copies an install command, scrolls through beats (why, compile, pipelines, interop, macros, tests, DOOM), clears doubts in FAQ, starts.

FIRST VIEWPORT: Centered elephant line-drawing that draws itself, italic headline with accent tail, two-line lede, paren-buttons, install console with Docker/Composer/PHAR tabs and copy, mono fact line.

FORM: Pinned brief (pi.dev grammar, Phel identity), user-selected; no seed roll.

Signature: per beat, the prose pins on the right while its proof scrolls past on the left (demos are taller than the prose, so a pinned demo would never release); the logo stroke draw on load; REPL typing replay.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
