# phel-lang.org

Zola static site for https://phel-lang.org: documentation, API reference, practice exercises, blog and release notes. The language lives in phel-lang/phel-lang.

## Where things live

| Path | What |
|---|---|
| `content/documentation/` | Docs: `language/`, `guides/`, `web/`, `libraries/`, `tooling/`, `reference/`, and the three start pages at the root |
| `content/practice/` | The practice journey, 11 modules from first steps to projects |
| `content/blog/`, `content/releases/` | Blog posts; release notes generated from GitHub releases |
| `templates/`, `templates/components/` | Tera 2 templates and the components content calls |
| `css/`, `static/` | Styles (built into `static/tailwind.css`), scripts, images |
| `build/` | PHP generators (API, errors, releases), the doc-snippet runner, their tests |
| `scripts/` | Node helpers: CSS concat, llms-full, doc dates, internal link check |

Policy lives in the rules below, for Claude Code and Codex alike. Edit only `.agnostic-ai/`. `CLAUDE.md`, `AGENTS.md` (root, `content/`, `content/practice/`), `.claude/`, `.codex/` and `.agents/` are generated by `agnostic-ai sync` and gitignored; a hook blocks hand edits to them and to the site's generated pages. Run `agnostic-ai sync` after pulling spec changes. Paths in rules and skills are relative to the repository root.
